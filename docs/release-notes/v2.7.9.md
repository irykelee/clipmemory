# 剪忆 ClipMemory v2.7.9 — 设置页新增版本对照 / Update Tab Now Shows Version Status

**发布日期 / Release Date**: 2026-08-05
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- **🆕 设置页更新源新增「当前版本 vs 最新版本」对照** — 一眼看出是否需要升级；尚未完成首次更新检查时仅显示当前版本，不显示"已是最新"标记，避免假绿

### 其他 (Other)

- **🛠 发布流程加固（REL-24..28 五轮优化）** — AI agent 5 条硬规则脚本头注释、`--yes` 非 TTY 双因子护栏、发布回滚工具（`Scripts/rollback-release.sh`）、发布后手动步骤确认 gate、release notes 默认描述自动填、bash 5.3 全角括号 unbound 变量 bug 修复
- **🛠 Homebrew tap CI 上线** — `irykelee/homebrew-clipmemory` 新增 `cask-audit.yml`（brew audit + brew style），从此 Cask 缩进 / stanza 顺序 / 格式错误能在发版前抓出，避免重复"tap Cask 不合规"事故
- **🛠 发布工具链实体化进主仓库** — `Scripts/release.sh` + `Scripts/rollback-release.sh` + `Scripts/README-release.md` + `Scripts/test/test_release.sh` 现已正式 git 跟踪（原先是 symlink 指向本地平行仓库 `ClipMemory-local`，任何人 clone 主仓库会得到断链的 symlink；该平行仓库于 2026-08-05 归档）
- **🛠 Tap Cask 模板化** — 新增 `Scripts/cask-template.rb`（rubocop-clean），Release workflow 用模板 + 占位符生成 tap Cask，告别内联 heredoc 引发的 YAML 缩进泄漏

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动升级模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **🆕 Update tab now shows a "Current vs Latest" version comparison** — one glance to see if an upgrade is needed; before the first check completes, only the current version is shown (no premature "up to date" mark)

### Other

- **🛠 Release tooling hardened (REL-24..28, five rounds of polish)** — 5 hard rules in the script header for AI agents, `--yes` non-TTY double-factor guard, `Scripts/rollback-release.sh` for undo, post-release manual-step confirmation gate, auto-filled release-notes default descriptions, and a bash 5.3 fullwidth-paren unbound-variable fix
- **🛠 Homebrew tap CI went live** — `irykelee/homebrew-clipmemory` now has a `cask-audit.yml` job (brew audit + brew style). Cask indent / stanza order / format errors are caught before release instead of in the user's `brew install`
- **🛠 Release toolchain materialized into the main repo** — `Scripts/release.sh` + `Scripts/rollback-release.sh` + `Scripts/README-release.md` + `Scripts/test/test_release.sh` are now properly git-tracked (previously symlinks to a local parallel repo `ClipMemory-local`, which would break for anyone cloning the main repo; that local repo was archived on 2026-08-05)
- **🛠 Tap Cask templated** — `Scripts/cask-template.rb` (rubocop-clean) replaces the inline heredoc in `release.yml`, eliminating the YAML-indent-leak class of bugs

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.7.9/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
