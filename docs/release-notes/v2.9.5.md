## English

### Highlights

- Long-press image preview now supports the full wheel-scroll interaction (USER-FEEDBACK-2026-09-26 multi-round iterative fix); alongside the audit-backlog closure + build-hygiene cleanup.

### Fixes
- **🖼 长按图片预览 — 滚轮滑动现在同时支持纵、横向 + Shift+wheel**
  - **Long-press image preview — wheel scroll now keeps the preview visible AND scrolls both axes.** Previous behavior dismissed the preview the moment the wheel scrolled (USER-FEEDBACK-2026-09-26, multi-round iterative fixes). Preview now stays shown during scroll and dismisses only on actual mouse-up.
  - Supports vertical scroll (default), horizontal scroll via Logitech side-button / Magic Mouse tilt / trackpad two-finger swipe, and horizontal scroll via Shift+wheel (the macOS-standard convention for ordinary mice). Scrollbar moves correctly when image exceeds preview window.
