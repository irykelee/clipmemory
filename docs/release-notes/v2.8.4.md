## 中文

### 主要更新 (Highlights)

- **🔒 Sparkle 升级 2.9.4 → 2.9.5 (ID-CI-0001)** — 升级含 "Harden patching delta file against symbolic link at destination path" 安全修复 (Sparkle 2.9.2 部分修复的完整版)。Sparkle 自动升级通道默认开启，用户无感；修复防止 delta patch 路径上的 symbolic link 攻击向量。

- **🍎 隐私清单 (PrivacyInfo.xcprivacy, ID-PRIVACY-0001)** — Apple 2024+ 要求：所有 macOS app 提交商店或走 Notarization 必须提供 `PrivacyInfo.xcprivacy`。本 release 新增此文件，声明 `NSPrivacyTracking=false`、`NSPrivacyCollectedDataTypes` 含剪贴板内容 + OCR text (linked + App Functionality 用途)、`NSPrivacyAccessedAPITypes` 覆盖 4 类 required-reason API (UserDefaults `CA92.1` / File Timestamp `C617.1` / Disk Space `E174.1` / System Boot Time `35F9.1`)。用户透明，但消除了开源分发到 Mac App Store 路径的合规壁垒。

- **🛠 4 项 latent bug 修复 (PR #61, ID-PR54-H/M1 + ID-PR56-L1/M)** — 4 项潜在 bug 真实修复（非 workaround）：
  - **PR54-H** — `ClipboardStore` 6 处直读 `items[items.firstIndex(where:)]` 抽 `resolvedIndex(for:)` chokepoint helper；原 6 处缺 bounds check，是 ID-CRASH-0001 staleness window 潜在 trap
  - **PR54-M1** — `FuzzySearchMatcher` 3 处 `.lowercased()` 改 `.lowercased(with: en_US_POSIX)`；原 host-locale-dependent 实现会把 Turkish `I→ı` / German `ß` 大写字母 cache 永久化，导致搜索 mismatch
  - **PR56-M** — 2 处 defensive `UserDefaults.standard` save/restore 死代码删除；XCTest 隔离架构生效后原代码是 no-op (store 走 `xcTestDefaults` isolated suite 不碰 `.standard`)
  - **PR56-L1** — `testMaxItems1000BoundaryNewUIPreset` 加 `contentCache.countLimit ≥ maxItems` assert；防未来 didSet 偷砍 cache rescale

- **📋 7 README 统一快捷键 + L10n 闭环 (ID-DOCS-0001)** — 7 语种 README 14 处 `Cmd+Ctrl+V` 残余 → `⌘⇧V` (匹配 `HotKeyManager.swift:10` defaultConfig `cmdKey | shiftKey`) + 7 L10n `settings.hotkey.footer` "open QuickBar" → "open main window" 统一（D-1 链路第 4 轮闭环）。新装用户按文档按 `⌘⇧V` 立即响应主窗口。

- **🛡 Hotkey drift CI lint 上线 (ID-CI-0002)** — 4 轮 Cmd+Ctrl+V ↔ ⌘⇧V churn 教训封板：`Scripts/lint-hotkey-drift.sh` 自动校验 7 README + 7 L10n footer 与 `HotKeyManager.swift:10` defaultConfig 一致性，禁历史漂移形式 (`Cmd+Ctrl+V` / `Ctrl+Cmd+V` / `⌘⌃V` / `Cmd+Shift+V`)，禁 footer 提 QuickBar。下次 hotkey 改 → CI 立即红 → 强制 6 层同步。

## English

### Highlights

- **🔒 Sparkle upgrade 2.9.4 → 2.9.5 (ID-CI-0001)** — Includes the "Harden patching delta file against symbolic link at destination path" security fix (the complete version of Sparkle 2.9.2's partial mitigation). The Sparkle auto-update channel is enabled by default — users won't notice the change; the fix prevents the symbolic-link attack vector on delta patch paths.

- **🍎 Privacy Manifest (PrivacyInfo.xcprivacy, ID-PRIVACY-0001)** — Required by Apple 2024+ for any macOS app heading to the Mac App Store or Notarization. This release adds the file declaring `NSPrivacyTracking=false`, `NSPrivacyCollectedDataTypes` for clipboard content + OCR text (linked, App Functionality purpose), and `NSPrivacyAccessedAPITypes` for 4 required-reason APIs (UserDefaults `CA92.1` / File Timestamp `C617.1` / Disk Space `E174.1` / System Boot Time `35F9.1`). Transparent to users; removes the compliance barrier for open-source distribution via the Mac App Store.

- **🛠 4 latent bug fixes (PR #61, ID-PR54-H/M1 + ID-PR56-L1/M)** — Real fixes (not workarounds):
  - **PR54-H** — 6 direct `items[items.firstIndex(where:)]` reads in `ClipboardStore` extracted into a `resolvedIndex(for:)` chokepoint helper; the original 6 sites lacked bounds checks, a latent trap in the ID-CRASH-0001 staleness window
  - **PR54-M1** — 3 `.lowercased()` calls in `FuzzySearchMatcher` switched to `.lowercased(with: en_US_POSIX)`; the host-locale-dependent version would permanently cache Turkish `I→ı` / German `ß` lowercased results, causing search mismatches
  - **PR56-M** — 2 defensive `UserDefaults.standard` save/restore dead-code sites removed; once the XCTest isolation architecture took effect, the original code became no-ops (the store path uses the `xcTestDefaults` isolated suite and never touches `.standard`)
  - **PR56-L1** — `testMaxItems1000BoundaryNewUIPreset` gained a `contentCache.countLimit ≥ maxItems` assertion; prevents future didSet regressions from silently shrinking cache rescale

- **📋 7 README hotkey + L10n consistency (ID-DOCS-0001)** — 14 `Cmd+Ctrl+V` residue lines across 7 README files updated to `⌘⇧V` (matching `HotKeyManager.swift:10` defaultConfig `cmdKey | shiftKey`) + 7 L10n `settings.hotkey.footer` entries aligned to "open main window" (D-1 chained to closing the 4th round). New users following the docs and pressing `⌘⇧V` will now get the main window immediately.

- **🛡 Hotkey drift CI lint enabled (ID-CI-0002)** — The 4-round Cmd+Ctrl+V ↔ ⌘⇧V churn lesson locked into a regression gate: `Scripts/lint-hotkey-drift.sh` automatically verifies 7 README + 7 L10n footer consistency against `HotKeyManager.swift:10` defaultConfig, forbids historical drift forms (`Cmd+Ctrl+V` / `Ctrl+Cmd+V` / `⌘⌃V` / `Cmd+Shift+V`), and bans QuickBar mentions in the footer. Any future hotkey change → CI red → 6-layer sync enforced.

### Upgrade Note

- Pure patch release: no breaking change, no API change, no data migration; v2.8.3 users upgrade with zero-visible-change
- Sparkle 2.9.5: auto-update channel handles the upgrade; security fix is invisible
- Privacy Manifest: transparent, no runtime impact
- 4 latent bug fixes: power users affected (5000+ items search diacritic correctness + chokepoint crash boundary), casual users no change
- README sync + L18 lint + hotkey drift lint: documentation and CI governance hardening, no day-to-day user impact

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
