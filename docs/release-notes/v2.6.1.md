# 剪忆 ClipMemory v2.6.1 — Audit Fixes & QuickBar Repair / 审计修复与快捷栏修复

**发布日期 / Release Date**: 2026-07-26
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- 修复了快捷栏「打开完整窗口」按钮第二次点击无反应的问题，菜单栏体验恢复流畅
- 全面代码审计后修复了 15 项潜在问题：加密密钥故障弹窗不再侵入底层服务、回收站独立模块化、OCR 错误可诊断、设置页视觉回归有守护

### 修复 (Fixes)

- **快捷栏「打开完整窗口」第二次无反应** — 窗口关闭后 @State 被重置，现在窗口实例保持稳定，每次点击都能正常打开
- **全新安装时加密密钥就绪前捕获的内容可能跨线程崩溃** — 极端情况下（首次启动的数毫秒内复制）不再触发并发异常
- **标签和回收站保存每次新建后台队列** — 批量操作（导入 100 个标签、清空回收站）不再产生资源抖动
- **OCR 无法区分「图片无文字」与「引擎错误」** — 现在错误时记录诊断日志，方便排查图片识别失败原因
- **设置页 4 个标签页无视觉回归守护** — 新增 snapshot 测试，字号/暗色模式切换不会再悄悄崩布局
- **15 个组件补全无障碍标签** — VoiceOver 用户可正常使用设置、标签、快捷栏等界面

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动升级模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- Fixed the QuickBar "Open Full Window" button becoming unresponsive on the second click — menu bar workflow is smooth again
- Comprehensive code audit addressed 15 issues: encryption-key alert decoupled from service layer, trash subsystem modularized, OCR errors now diagnosable, settings tabs visually regression-guarded

### Fixes

- **QuickBar "Open Full Window" unresponsive on second click** — @State now survives window close/reopen cycles, every click works
- **Cross-thread crash possible on fresh install captures before crypto key ready** — deferred captures now properly dispatch to main thread
- **Tag and trash save created new dispatch queues on every call** — batch operations (100 tags import, empty trash) no longer produce resource churn
- **OCR couldn't distinguish "no text" from "engine failure"** — diagnostic logging now records Vision errors for troubleshooting
- **4 settings tabs had no visual regression coverage** — new snapshot tests guard against layout breakage on font/theme changes
- **15 components gained accessibility labels** — VoiceOver users can now navigate settings, tags, QuickBar, and welcome screen

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.6.1/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
