# 剪忆 ClipMemory v2.6.0 — 独立设置窗口 / Standalone Settings window

**发布日期 / Release Date**: 2026-07-25
**类型 / Type**: Minor release（全新设置窗口 + macOS 26 Tahoe 适配 + 34 项审计修复 / New Settings window + macOS 26 Tahoe adaptation + 34 audit fixes）

## 中文

### 主要更新 (Highlights)

- **⚙️ 全新独立设置窗口** — 设置从主窗口侧边栏迁出，改为独立窗口，顶部按「常规 / 历史与捕获 / 备份 / 更新与关于」四组分页；`⌘,`、菜单栏图标、Quick Bar 菜单均可直达，窗口不再随主窗口开关而丢失
- **🖥 全面适配 macOS 26 Tahoe** — 主窗口标题栏恢复与侧边栏融合的磨砂质感（不再是突兀的白色条带）；修复 Tahoe 上设置下拉菜单选项全部显示 `(null)` 的系统 stringsdict 渲染问题
- **🔤 字号设置即时生效** — 小/中/大切换后所有列表、标签、弹窗文字立即重排，不再需要重启 App
- **🛡 34 项审计修复落地** — 全新安装首次复制不再因密钥初始化竞态丢条目；OCR 识别结果改为随保存节奏落盘，断电不再整批丢失；备份导入在合并数据前先校验清单，损坏包更早报错

### 新功能 (New Features)

- **独立设置窗口（4 组分页）** — 设置项按主题分组，页面不再无限变长；支持 `⌘,` 快捷键与菜单栏入口
- **Quick Bar 直达设置** — 菜单栏弹出的 Quick Bar 底部新增「偏好设置」项

### 修复 (Fixes)

**数据与隐私**

- **全新安装首条复制丢失（H-2）** — 密钥首次生成期间的剪贴板内容改为排队等待，密钥就绪后补录，不再静默丢弃
- **OCR 结果断电丢失（H-1）** — OCR 回填从立即写盘改为跟随常规保存节奏，崩溃/断电不再丢掉整批识别结果
- **超大富文本粘贴（M-1）** — RTF 粘贴数据加入体积上限，异常大的粘贴不再拖慢捕获
- **备份导入校验提前（M-9）** — 清单计数校验先于数据合并与图片导入执行

**界面与交互**

- **关闭全部窗口后无法重新打开主窗口** — 菜单栏「Open Clipboard」现在总能把主窗口带到当前空间最前
- **点侧边栏「偏好设置」主内容区闪一下** — 直接打开设置窗口，不再先切换主窗口面板
- **设置下拉菜单显示 `(null)`** — 弃用 Tahoe 上渲染异常的 stringsdict 复数机制，改为显式本地化字符串
- **侧边栏顶部留白过大** — logo 与红绿灯间距收窄

**性能**

- **保存定时器复用（M-2）** — 不再频繁销毁重建调度器
- **OCR 语言列表与正则静态缓存（M-6/M-7）** — 重复调用不再每次重新枚举/编译
- **旧版图片迁移批量写入（M-8）** — 迁移大量图片时不再每张都写一次偏好设置

### 升级提示 (Upgrade Note)

- 设置界面迁移为独立窗口，原侧边栏「偏好设置」入口保留，习惯不变
- v2.4.0 起带自动升级模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **⚙️ All-new standalone Settings window** — Settings moves out of the main-window sidebar into its own window with four tabbed groups (General / History & Capture / Backup / Updates & About); reachable via `⌘,`, the menu-bar icon, and the Quick Bar menu, and no longer tied to the main window's lifecycle
- **🖥 Full macOS 26 Tahoe adaptation** — the main window's title bar once again blends into the sidebar material (no more stark white strip); fixes a Tahoe stringsdict rendering issue that made Settings dropdown options all show `(null)`
- **🔤 Font-size setting applies instantly** — switching between small/medium/large re-renders every list, tag, and panel immediately, no restart needed
- **🛡 34 audit fixes shipped** — a fresh install's first copies no longer vanish to a key-initialization race; OCR results are flushed on the regular save cadence instead of being lost in a crash; backup imports validate the manifest before merging any data

### New Features

- **Standalone Settings window (4 tab groups)** — settings are grouped by topic so the page no longer grows forever; `⌘,` and menu-bar entry supported
- **Settings from Quick Bar** — the menu-bar Quick Bar gains a "Settings" item at the bottom

### Fixes

**Data & privacy**

- **First copies lost on a fresh install (H-2)** — clipboard content arriving during first-time key generation is now queued and recorded once the key is ready
- **OCR results lost on power loss (H-1)** — OCR backfill now follows the regular save cadence instead of immediate writes
- **Oversized rich-text pastes (M-1)** — RTF paste data is now size-capped so pathological pastes can't stall capture
- **Backup validation moved earlier (M-9)** — manifest counts are checked before any store merge or image import

**UI & interaction**

- **Main window couldn't be reopened after closing all windows** — "Open Clipboard" from the menu bar now always brings the main window to the active Space, frontmost
- **Flicker when opening Settings from the sidebar** — the Settings window now opens directly without swapping the detail pane
- **Settings dropdowns showed `(null)`** — the broken stringsdict plural mechanism on Tahoe was retired in favor of explicit localized strings
- **Excess whitespace above the sidebar logo** — the gap below the traffic lights is tightened

**Performance**

- **Save timer reuse (M-2)** — the scheduler is no longer torn down and rebuilt on every save
- **Static caches for OCR languages and regexes (M-6/M-7)** — repeated calls no longer re-enumerate or recompile
- **Batched writes during legacy image migration (M-8)** — migrating many images no longer writes preferences once per image

### Upgrade Note

- Settings moved to a standalone window; the sidebar "Settings" entry remains, so existing habits keep working
- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.6.0/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
