# 剪忆 ClipMemory v2.7.6 — 稳定性与数据安全加固 / Stability & Data-Safety Hardening

**发布日期 / Release Date**: 2026-08-01
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- **过期自动清理改为进回收站，置顶条目永久豁免** — 达到保留上限的自动清理此前会永久删除条目；现在改为移入回收站（可随时找回），且置顶（收藏）条目不再被自动清理
- **加密链路加固** — 密钥链读取出错时不再误覆盖根密钥（避免极端情况下全部历史无法解密）；废弃密钥文件改为安全覆写后删除；备份目录权限收紧为仅本人可读
- **OCR 更健壮** — 图片文字识别遇到瞬时失败（如系统资源紧张）时，下次启动自动重试，不再永久跳过

### 修复 (Fixes)

- **修复解密失败条目偶发显示「无法读取」并被缓存** — 密钥就绪晚于界面加载时的偶发空白/误报，现在会自动重试恢复显示
- **修复 QuickBar 搜索框键盘死区** — 搜索框聚焦时 Enter（复制选中项）与 Esc（关闭）此前无效，现已恢复
- **修复标签选择器 Done 按钮不可用** — 新建标签或采纳建议标签后，Done 按钮此前保持禁用，现已修复
- **修复搜索高亮偶发崩溃** — 搜索含特殊 Unicode 字符（如德文 ß）的内容时，大小写展开可能触发越界崩溃
- **修复单个损坏标签连坐全部标签丢失** — 标签数据单条损坏时不再拖垮整个标签列表
- **修复自动备份两处停摆** — 系统时钟回拨后自动备份不再停止；调低备份保留份数后立即清理旧备份
- **修复备份密码错误误报** — 备份文件本身损坏时此前误报「密码错误」，现已能正确区分
- **修复外来剪贴板变更被静默吞掉** — App 自身写入剪贴板的豁免窗口内，其他 App 的写入不再被丢弃
- **性能与内存优化** — 图片缓存占用估算更精确（避免内存压力），解密失败合并与标签建议分析更快
- **无障碍与多语言** — 中日韩语言的「1 条」单数文案不再误用英文；回收站敏感文字写入剪贴板时增加隐私标记

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动更新模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **Expired items now go to Trash; pinned items are exempt** — automatic cleanup previously deleted expired items permanently; they now move to Trash (recoverable anytime), and pinned items are never auto-cleaned
- **Encryption hardening** — a transient Keychain error no longer risks overwriting the root key (which could have made all history undecryptable); retired key files are now securely overwritten before deletion; the backup directory is now readable only by you
- **More resilient OCR** — transient recognition failures (e.g. system resource pressure) are retried on next launch instead of being skipped forever

### Fixes

- **Fix spurious "unreadable" items getting cached** — when the encryption key became ready after the UI loaded, rows could show a false error that stuck; they now retry and recover automatically
- **Fix QuickBar search-field keyboard dead zone** — Enter (copy selection) and Esc (dismiss) did nothing while the search field was focused
- **Fix tag picker Done button staying disabled** — creating a tag or accepting a suggestion did not enable Done
- **Fix rare crash in search highlighting** — case-expansion of special Unicode characters (e.g. German ß) could crash the highlighter
- **Fix one corrupted tag wiping the whole tag list** — a single malformed tag entry no longer takes down all tags
- **Fix two auto-backup stalls** — backups no longer stop after the system clock jumps backward; lowering the retention count prunes old backups immediately
- **Fix wrong "incorrect password" errors** — a corrupted backup file is now distinguished from a wrong password
- **Fix external clipboard changes being silently dropped** — changes from other apps during the self-write grace window are no longer discarded
- **Performance & memory** — more accurate image-cache cost accounting (less memory pressure), faster decryption-failure merging and tag-suggestion analysis
- **Accessibility & localization** — CJK singular ("1 item") strings no longer fall back to English; sensitive trash text copied to the pasteboard now carries a privacy marker

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.7.6/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
