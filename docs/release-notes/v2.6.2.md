# 剪忆 ClipMemory v2.6.2 — 图片搜索高亮与标签筛选 / Image Search Highlight + Tag Filter Fix

**发布日期 / Release Date**: 2026-07-27
**类型 / Type**: Minor release

## 中文

### 主要更新 (Highlights)

- **图片搜索结果直接显示 OCR 文字**：主列表和快速弹出框中，截图条目下方会出现青色高亮的识别片段，匹配搜索词的部分醒目可见。设置 → 历史记录中可关闭（仅关闭显示，过滤仍生效）。
- **标签筛选改为「同时包含」语义**：勾选多个标签时（如「中国大陆」+「2026」），只显示同时被打上这两个标签的条目，不再是任一标签即命中。
- **标签筛选时主列表顶部出现提示条**：当前激活的标签以胶囊形式列出，每个胶囊右侧 × 可单独移除，右侧「全部清除」可一键清空；同时显示「显示 X / 共 Y 条」数量，一眼看出过滤生效。
- **搜索框右侧增加 × 一键清空按钮**：搜完一个关键词后点 × 直接清空，无需逐字删除；搜索框自动获得焦点，可立即输入下一个关键词。
- **回收站删除后列表即时刷新**：之前删除回收站条目后需要触发其他操作才能看到列表刷新，现在点完「永久删除」/「清空」立即生效。
- **编辑标签弹窗大幅改版**：默认显示检测到的名称（可关闭）；底部完成按钮移到最下方并与取消按钮并列；未做任何修改时完成按钮为灰色，避免误判已保存；预览区域显示完整内容（不再是 60 字符截断），长内容支持滚动。
- **检测到的名称常见虚词过滤**：英文常见的「is」「has」「this」「the」等不再被误识为名称；中文识别仍受 Apple 模型能力限制，已通过顶部开关让用户主动控制。

### 修复 (Fixes)

- **OCR 搜索高亮的多种边界条件**：包含土耳其字符 `İ`、`ß` 等特殊字符现在能正确匹配；Unicode 大小写折叠不再触发越界崩溃；多行内容正确换行。
- **回收站过期清理**：长时间运行的会话也能定期清理过期回收项，不再需要等到下次启动。
- **删除 / 清空回收站后列表不刷新**：之前操作后界面不更新，已修复。
- **标签编辑 trim 空白**：创建标签时名字自动去除首尾空白。
- **搜索时分组头部不可点击**：避免搜索时点分组头部切换出现的视觉错乱。
- **6 项审计修复**：包括设置页预览、快速弹出框窄窗口等回归问题（详见技术更新）。

### 其他 (Other)

- 编辑标签弹窗的预览区域字体从 11 磅调整到 13 磅，长内容阅读更轻松。
- 设置页新增「在搜索结果中显示 OCR 文字预览」开关。

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动升级模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **OCR text shown directly under image search results**: cyan-highlighted OCR snippets now appear beneath screenshot rows in both the main list and QuickBar popover; matches the search term. Settings → History Capture has a toggle to disable the display (filter still works).
- **Tag filter now uses AND (intersection) semantics**: selecting multiple tags (e.g. "Mainland China" + "2026") shows only items tagged with **both**, not items matching either. Matches Finder smart folders / Gmail multi-label behavior.
- **Active tag filter shown as a chip strip with count**: main list now displays currently selected tags as chips (each with its own × to remove that tag), plus a "Show all" link and a "Showing X of Y items" badge so users can see the filter is active at a glance.
- **× clear button in the search field**: clear the current search in one tap instead of backspacing character by character; the search field auto-refocuses so you can type the next query immediately.
- **Trash tab list refreshes immediately after delete**: deleting or emptying the trash now updates the visible list right away, instead of waiting for some other action to trigger a re-render.
- **Edit-tag sheet redesigned**: detected names shown by default (toggle preserved); Done button moved to the bottom of the window next to Cancel (Done is greyed out until you actually make a change); preview area shows full content instead of a 60-char truncation, with scroll for long entries.
- **English stop-word filter for detected names**: common English function words (is, has, this, the, etc.) no longer misidentified as entities. Chinese NER remains limited by Apple's on-device model — toggle is the escape hatch.

### Fixes

- **OCR search highlight edge cases**: special characters (Turkish `İ`, German `ß`, etc.) now match correctly; Unicode case-folding no longer traps; multi-line content wraps properly.
- **Trash expiration cleanup runs periodically**: long-running sessions no longer accumulate expired trash until next launch.
- **Trash list did not refresh after delete / empty**: UI now updates immediately.
- **Tag picker: trim whitespace**: tag names auto-trim leading/trailing whitespace.
- **Group header not toggleable while searching**: prevents visual confusion when tapping a group header during a search.
- **Plus 6 audit fixes** for OCR preview, QuickBar narrow window, and related regressions (see Technical Notes).

### Other

- Edit-tag preview font bumped 11pt → 13pt for easier reading of long entries.
- Settings → History Capture: new "Show OCR text in image search results" toggle.

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`
