# 剪忆 ClipMemory v2.5.13 — 审计修复扫尾 / Audit-fix sweep

**发布日期 / Release Date**: 2026-07-25
**类型 / Type**: Patch release（31 项审计残留修复 + 发布管线加固 / 31 audit follow-up fixes + release-pipeline hardening）

## 中文

### 主要更新 (Highlights)

- **🛡 历史数据更抗损** — 未来版本新增条目类型后，旧版本打开不再整个清空历史（未知类型降级为纯文本保留）；备份包清单新增计数/盐长度/版本下限校验，损坏包明确报错而不是静默导入一半
- **🔒 密码管理器内容不再被捕获** — 识别 `ConcealedType`/`TransientType` 剪贴板标记，1Password 等应用复制的内容按系统约定直接跳过
- **⚡ 复制图片不再卡顿** — 复制未缓存图片时磁盘读取与解密移到后台，主线程不再被阻塞
- **🌐 更新源状态面板说人话** — 「最近切换」不再显示英文枚举原文，改为 7 语言本地化文案，且只有真正发生切换时才记录
- **🇰🇷 韩语 README 修正** — 两处混入的日语残句改回韩语

### 修复 (Fixes)

**捕获与隐私**

- **密码管理器复制内容跳过（CLIP-6）** — 命中系统隐藏/瞬态标记时无条件不捕获，覆盖 0.5 秒应用归因缺口
- **自身写入重复捕获竞态（CLIP-4）** — 复制写入落地前的计时器 tick 不再消耗跳过标志，不再偶发重复条目
- **OCR 明文缓存随条目清除（CLIP-5）** — 删除/清理条目时 `.ocr` 缓存键一并移除，不再长期驻留内存

**数据与备份**

- **条目类型解码前向兼容（CLIP-7）** — 遇到未知类型降级为文本条目，不再导致全部历史解码失败
- **备份包清单校验（BKP-4）** — 导入核对条目/标签/图片计数与清单声明，盐长度 ≥16 字节，格式版本 ≥1；不符按包损坏报错
- **图片读取大小预检（STOR-5）** — 超过 50 MB 上限的图片不再无界读入内存
- **备份目录名识别改用日期解析 round-trip（L-13）** — 格式与识别器不再靠人工同步

**界面与交互**

- **更新源面板本地化 + 真切换才记录（UPD-3）** — 6 个切换原因文案 × 7 语言
- **热键录制取消正确停止监听（CLIP-6 主界面）** — Settings 的 Cancel 按钮与 Esc 行为一致
- **已卸载的排除应用可见可删（次级 CLIP-4）** — 不再从设置页神秘消失但持续生效
- **图片预览面板按目标屏幕居中（次级 CLIP-5）** — 多屏不再飘到主屏
- **字号设置抗损坏（模型 CLIP-3）** — 行视图字号全部经过 `sz()` 守卫，UserDefaults 写入异常值不再塌布局
- **OCR 语言回退修正（模型 CLIP-5）** — 回退目标本身不支持时改取首个受支持语言
- **FlowLayout 换行条件统一（次级 CLIP-7）** — 零尺寸子视图不再导致尺寸报告与摆放错位
- **标签 chip 跟随字号设置即时刷新（次级 CLIP-6）**

**基础设施**

- **镜像日期解析兼容命名时区（UPD-4）** — `GMT` 等写法解析失败不再让镜像陈旧守卫静默失效
- **卡顿检测心跳基线修正（INFRA-4）** — 启动不再复用冻结的初始时间戳
- **窗口缩放按所在屏幕计算（INFRA-5）** — 多屏 zoom/恢复不再用错屏幕

**发布管线**

- **tap 仓库 token 不再写入 git config（REL-10）** — 改 extraheader 模式
- **CI 缓存短路（REL-11）** — Sparkle 已缓存时跳过重复下载，ci.yml 加 xcodegen 守卫
- **README 同步原子写（REL-12）** — 全部语言在内存构建成功后才统一落盘，不再留下翻译到一半的文件
- **test-ui.sh 按 PID 精确采样（REL-13）**

### 升级提示 (Upgrade Note)

- v2.5.12 及以上：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **🛡 Harder to lose history** — unknown item types from a future version now degrade to plain text instead of failing the entire history decode; backup manifests gain count/salt/version validation so corrupt packages fail loudly instead of importing halfway
- **🔒 Password-manager copies are no longer captured** — `ConcealedType`/`TransientType` pasteboard markings are honored, so content copied from 1Password and similar apps is skipped per the system convention
- **⚡ Image copies no longer stall the UI** — disk reads and decryption for uncached images now happen in the background instead of on the main thread
- **🌐 Update-source panel speaks your language** — the "last switch" line no longer shows raw English enum tokens, uses 7-language localized text, and only records genuine switches
- **🇰🇷 Korean README corrected** — two stray Japanese fragments are Korean again

### Fixes

**Capture & privacy**

- **Password-manager copies skipped (CLIP-6)** — concealed/transient pasteboard types are never captured, closing the 0.5 s app-attribution gap
- **Own-write re-capture race (CLIP-4)** — a timer tick landing before the write no longer consumes the skip flag, so occasional duplicate entries stop
- **OCR plaintext cache evicted with its item (CLIP-5)** — `.ocr` cache keys are removed on delete/cleanup instead of lingering in memory

**Data & backup**

- **Forward-compatible item-type decoding (CLIP-7)** — unknown types degrade to text entries instead of failing the whole history decode
- **Backup manifest validation (BKP-4)** — item/tag/image counts are cross-checked, salt must be ≥16 bytes, format version ≥1; mismatches fail as corrupt
- **Image read size pre-check (STOR-5)** — images over the 50 MB cap are no longer read into memory unbounded
- **Backup dir recognition via date round-trip (L-13)** — the recognizer and the format constant can no longer drift apart

**UI & interaction**

- **Update-source panel localized, genuine switches only (UPD-3)** — 6 reason strings × 7 languages
- **Hotkey-recording Cancel stops the monitor (main CLIP-6)** — Settings' Cancel now behaves like Esc
- **Uninstalled excluded apps stay visible and removable (secondary CLIP-4)** — no longer hidden while still in effect
- **Image preview centers on the target screen (secondary CLIP-5)** — no longer jumps to the main display on multi-monitor setups
- **Font scale hardened (model CLIP-3)** — all row sizing goes through the `sz()` guard, so a corrupted UserDefaults value can't collapse the layout
- **OCR language fallback corrected (model CLIP-5)** — falls back to the first supported language when English itself is unavailable
- **FlowLayout line-break condition unified (secondary CLIP-7)** — zero-size children no longer desync reported size from actual placement
- **Tag chips refresh immediately on font-scale change (secondary CLIP-6)**

**Infrastructure**

- **Feed date parsing accepts named timezones (UPD-4)** — `GMT`-style dates no longer silently disable the mirror staleness guard
- **Hang-detector heartbeat baseline fixed (INFRA-4)** — startup no longer reuses a frozen initial timestamp
- **Window zoom uses the window's own screen (INFRA-5)** — multi-monitor zoom/restore no longer targets the wrong display

**Release pipeline**

- **Tap-repo token no longer written to git config (REL-10)** — switched to the extraheader pattern
- **CI cache short-circuit (REL-11)** — cached Sparkle is no longer re-downloaded; ci.yml gains an xcodegen guard
- **README sync writes atomically (REL-12)** — all languages are built in memory before any file hits disk
- **test-ui.sh samples CPU by exact PID (REL-13)**

### Upgrade Note

- v2.5.12+: wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.5.13/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware.
