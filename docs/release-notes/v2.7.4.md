## 中文

### 主要更新 (Highlights)

- **🔍 6 项 OCR 优化（CJK / 去重 / 超时 / 内存）** — CJK 识别降级时新增通知与 userLocale 日志、图片去重后旧 UUID 的 OCR 结果不丢、Vision 调用 15 秒自动取消、6K HEIC 预览内存从 ~100 MB 降至 ~16 MB（`thumbnailMaxPixelSize=2048`）
- **⚡️ 搜索 / 复制性能提升（多项后台优化）** — UUID→索引字典 O(1) 查找、拼音结果按内容缓存（1000 次匹配从 1340 ms 降至 77 ms）、JSONEncoder 复用、cleanup 单遍扫描、cold-start AES-GCM 预填
- **🖼️ 宽图长按预览不再白屏** — 主屏旋转为 portrait 时复制 16:9 截图，1 像素超出 cap 宽度的边界情况不再产生 2000+ 像素白底（panel 自动贴合图片尺寸）
- **🔇 OCR 路径加最小文字高度阈值** — `minimumTextHeight = 0.01`（默认 0.02 是为印刷文档调校的），小字号终端截图 / 12-pt 视网膜截图现在能被识别
- **🌐 7 语言本地化补完** — 标签徽章无障碍、tag picker 添加建议、加密失败提示等多种数 L10n 修复

### 修复 (Fixes)

- **🖼️ 宽图长按预览白屏** — portrait-rotated 主屏 + 16:9 横向截图（1313×226 在 1216×2277 cap 上）的 1 像素超宽边界情况，panel 不再被强行撑成 cap 大小
- **🖼️ 重复复制图片时旧 UUID 的 OCR 结果不丢** — 之前 image dedup 把新 UUID 丢掉，OCR 完成时找不到 item 静默丢弃结果（用户无法重试失败 OCR）
- **🔍 Vision OCR 不再无限期阻塞队列** — 加 15 秒看门狗 + `request.cancel()` 保护，畸形 TIFF / 截断 IDAT PNG 不再卡死串行队列
- **🔍 CJK 识别降级时新增用户可见通知** — macOS locale 表缺 zh-Hans / zh-Hant / ja / ko 时，OCR 静默降级到英文现在有 `.ocrLanguageFallback` 通知 + `userLocale` 日志
- **🔍 OCR 6K HEIC 不再爆内存** — `CGImageSourceCreateThumbnailAtIndex` 2048 px 上限（自动处理 EXIF 旋转），backfill 峰值从 ~400 MB 降至 ~64 MB
- **📝 主列表行解密失败永久污染** — 之前 Keychain 瞬态锁定触发的 `decryptionFailed=true` 会永久标记条目，下一次启动（key 恢复后）依然空白；现在 `loadItems` 启动时自动重置 flag，display 路径重新尝试
- **📝 剪贴板项行长按解密空白** — `.task` 触发时机早于 `prepareKey` 完成时，第一帧拿到空 AttributedString 并被 highlight cache 缓存（cache poison）；200ms 自动重试 + cache key 加入 `decryptedContent.hashValue`
- **⚡️ QuickBar 选中行不显示** — `decryptedContent.hashValue` 加入 highlight cache key（修上面那条 cache poison 的连锁影响）
- **🔁 关闭主窗口时 welcome 闪烁** — 撤回一次无效的 `refreshAndPrewarm` 拆分（`ID-LIFE-0019` 改成更简单实现）

- 7 语言用户：升级后立即生效；OCR 改进无需额外配置

## English

### Highlights

- **🔍 6 OCR improvements (CJK / dedup / timeout / memory)** — `.ocrLanguageFallback` notification + `userLocale` log on CJK downgrade, OCR result routed via `contentHash` fallback when image dedup drops the new UUID, 15 s `request.cancel()` watchdog on Vision calls, 6K HEIC preview memory from ~100 MB → ~16 MB via `thumbnailMaxPixelSize=2048`
- **⚡️ Search / copy performance (multiple background optimizations)** — UUID→index dict O(1) lookup, pinyin result cache per content (1000 matches 1340 ms → 77 ms), JSONEncoder reuse, single-pass cleanup, cold-start AES-GCM prefill
- **🖼️ Wide-image long-press preview no longer white-screens** — On portrait-rotated main display, a 16:9 landscape screenshot (1313×226 on 1216×2277 cap) no longer produces a 2000+ px white strip below the image
- **🔇 OCR with smaller minimum text height** — `minimumTextHeight = 0.01` (default 0.02 is tuned for printed documents), small-font terminal screenshots / 12-pt Retina captures now recognized
- **🌐 7-language localization polish** — Tag badge accessibility, tag picker add-suggestion, encrypt-failed prompt — multiple L10n fixes

### Fixes

- **🖼️ Wide-image long-press preview white screen** — 1-pixel-over-cap wide case on portrait-rotated main display no longer forces panel to cap size
- **🖼️ OCR result for deduped-away image UUID no longer lost** — When image dedup drops the new UUID, the OCR completion found no item and silently discarded the result; users could never retry failed OCR on re-copy
- **🔍 Vision OCR no longer blocks queue indefinitely** — 15 s watchdog + `request.cancel()`; malformed TIFF / truncated IDAT PNG no longer hangs the serial queue
- **🔍 CJK recognition downgrade now user-visible** — When macOS locale table drops zh-Hans / zh-Hant / ja / ko, silent fallback to English now posts `.ocrLanguageFallback` notification + `userLocale` log
- **🔍 OCR 6K HEIC no longer spikes memory** — `CGImageSourceCreateThumbnailAtIndex` 2048 px cap (EXIF orientation preserved in same pass); backfill peak ~400 MB → ~64 MB
- **📝 Main-list row decryption failure no longer permanent** — Keychain transient lock's `decryptionFailed=true` permanently marked the item; next launch (with key recovered) still showed blank. `loadItems` now resets the flag on startup; display path retries
- **📝 Clipboard item row long-press decryption blank** — `.task` fired before `prepareKey` completed; first frame got empty `AttributedString` cached as highlight; 200 ms auto-retry + cache key now includes `decryptedContent.hashValue`
- **⚡️ QuickBar selected row not displayed** — `decryptedContent.hashValue` added to highlight cache key (chained fix for the cache poison above)
- **🔁 Welcome flash on close main window** — Reverted an ineffective `refreshAndPrewarm` split (`ID-LIFE-0019` replaced with simpler impl)

### Upgrade Note

- v2.7.3 or earlier: wait for in-app auto-update, or run `brew upgrade --cask clipmemory`
- **First launch after upgrade** runs the startup image integrity scan (same as v2.7.2; non-blocking); items marked ⚠️ can be inspected in Trash
- 7-language users: takes effect immediately on upgrade; OCR improvements need no extra setup
