# 剪忆 ClipMemory v2.10.0-beta.1 — 预发布通道上线，要不要收 beta 由你决定 / The beta channel is here — opt in when you want it

**发布日期 / Release Date**: 2026-11-08
**类型 / Type**: Pre-release（预发布）

## 中文

### 主要更新 (Highlights)

- **🧪 现在由你决定要不要收预发布版本** —— 「设置 → 更新」里多了一个「**接收 beta 版更新**」开关。勾上之后，ClipMemory 会开始接收**预发布**（beta）版本；不勾就只收正式版。预发布版本可能带着还没做完的功能，随时可以关掉切回正式版。

### 其他 (Other)

- 这一版 beta 的重点是**发布机制本身**：预发布版本从此**只推给愿意试的人**，不再随正式版推给全体用户；`brew upgrade` 也**不会**拿到 beta。
- 其余改动集中在发布链路的可靠性（发版前的自动检查、appcast 条目的版本与通道标注、发布后的自动验收），用户可见的行为变化只有上面那一条。

### 升级提示 (Upgrade Note)

- **正式版用户不会自动收到这一版** —— beta 通道是**主动加入**的（ID-BETA-0001）。
- 想试：设置 → 更新 → 勾上「接收 beta 版更新」→ 点「立即检查更新」。
- 想回正式版：关掉那个开关即可 ⇒ 正式版条目仍在默认通道，不受影响。
- 数据仍加密存储在本地、密钥仍在 Keychain，存储位置与加密格式**均未改变**。
- ⚠️ beta 版本号形如 `2.10.0-beta.1`，Sparkle 按构建号（`CFBundleVersion`）比较 ⇒ 它的版本**低于**同号的正式版 ⇒ ⇒ 正式版发布后，beta 用户会收到正式版。

### 验证 (Verification)

- 1448 个测试：1444 通过 / 4 跳过 / 0 失败（4 个跳过项是既有的 snapshot golden 失配项，与本版无关）。
- 19 个发布与守卫脚本在 CI 里实跑全部通过 —— 其中 9 个脚本**此前从未在 CI 里跑过**（本版把它们接了进去，并顺手修好了两个**过期**的断言）。
- beta 发版的**发布后验收**已机械化：`bash Scripts/verify_beta_release.sh v2.10.0-beta.1` ⇒ 一次核对「appcast 里有带 beta 通道的条目 / 版本号分裂正确 / 正式条目仍在 / Release 标了 prerelease / **Homebrew tap 没有被指向 beta**」。

## English

### Highlights

- **🧪 Opting into pre-releases is now your call** — Settings → Update gained a **"Receive beta updates"** switch. Turn it on and ClipMemory starts picking up **pre-release (beta)** builds; leave it off and you get stable releases only. Pre-releases may contain unfinished work, and you can flip the switch back at any time.

### Other

- This beta is mostly about the **release mechanism itself**: pre-releases now reach **only the people who asked for them** instead of riding along with every stable release, and `brew upgrade` will **never** pull a beta.
- The remaining changes harden the release chain (pre-release checks, the appcast item's version and channel tagging, post-release verification). The only user-visible behaviour change is the one above.

### Upgrade Note

- **Stable users will not get this build automatically** — the beta channel is **opt-in** (ID-BETA-0001).
- To try it: Settings → Update → enable "Receive beta updates" → "Check for Updates".
- To go back: turn the switch off ⇒ stable items stay on the default channel, unaffected.
- Your data is still encrypted locally and the key still lives in your Keychain; neither the storage location nor the encryption format changed.
- ⚠️ Beta versions look like `2.10.0-beta.1`. Sparkle compares the **build number** (`CFBundleVersion`), so a beta sorts **below** the matching stable release ⇒ ⇒ once the stable release ships, beta users receive it.

### Verification

- 1448 tests: 1444 passed / 4 skipped / 0 failures (the 4 skips are pre-existing snapshot-golden mismatches, unrelated to this build).
- 19 release and guard scripts now run in CI — **9 of them had never run in CI before** (this release wired them up and, in the process, fixed two **stale** assertions).
- The **post-release acceptance** for beta builds is mechanised: `bash Scripts/verify_beta_release.sh v2.10.0-beta.1` checks, in one go, that the appcast carries a beta-tagged item, the version split is right, stable items are still there, the Release is marked as a prerelease, and the **Homebrew tap was not pointed at the beta**.
