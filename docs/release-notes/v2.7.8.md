# 剪忆 ClipMemory v2.7.8 — 设置说明与搜索体验优化 / Settings Clarity & Search Polish

**发布日期 / Release Date**: 2026-08-04
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- **🔍 搜索框改为 macOS 26 系统默认样式** — 侧边栏搜索框带圆角放大镜图标与聚焦高亮，观感与系统设置一致；最小窗口尺寸提升至 850×600，长标签列表不再拥挤
- **📖 设置页 6 处新增使用说明** — 热键、历史上限、OCR、排除应用、备份、升级源各有逐条说明，不再靠截图猜操作；「显示 OCR 文本」明确为只控制搜索结果预览、不影响识别本身
- **🏷️ 品牌 Logo 跨语种统一** — 中文「剪忆」与英文「ClipMemory」字号一致，切换语言时品牌标识不再忽大忽小
- **🗓️ 日期筛选移到列表头标签条旁** — 工具栏回归清爽，只留核心操作
- **⚡ 启动预热节流（5 秒）** — 冷启动时视图预热不再一次性重载，减少卡顿

### 修复 (Fixes)

- **工具栏 Logo 内边距与日期筛选胶囊对齐** — 视觉间距一致
- **侧边栏搜索与工具栏布局重排** — 搜索入口更显眼，工具栏不再拥挤溢出
- **最小窗口宽度 640→800、高度 440→600** — 窄窗口下工具栏项目不再被收进溢出菜单

### 其他 (Other)

- **设置窗口居中显示** — 打开设置时不再出现在屏幕边缘
- **测试隔离加固（M13 根因修复）** — 内部可靠性提升，不影响使用方式

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动升级模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **🔍 Search box restyled to match the macOS 26 system default** — rounded magnifier chip with focus highlight, consistent with System Settings; minimum window size raised to 850×600 so long tag lists no longer feel cramped
- **📖 Six settings items now have in-context explanations** — hotkey, history limits, OCR, excluded apps, backup, and update source each explain what they do, so users no longer guess from screenshots; "Show OCR text" now clearly states it only controls the preview in search results, not recognition itself
- **🏷️ Brand logo unified across locales** — "剪忆" and "ClipMemory" share the same point size, so the brand mark no longer changes scale when switching languages
- **🗓️ Date filter moved next to the tag strip in the list header** — the toolbar is back to essentials
- **⚡ Startup prewarm throttled (5s)** — cold-start view prewarm no longer reloads in one burst, reducing lag

### Fixes

- **Toolbar logo padding aligned with the date-filter capsules** — consistent visual spacing
- **Sidebar search and toolbar layout reworked** — search is more prominent; the toolbar no longer overflows on narrow windows
- **Min window width 640→800, height 440→600** — toolbar items stay visible instead of collapsing into the overflow menu

### Other

- **Settings window now centers on the main window** — no longer opens at the screen edge
- **Test isolation hardening (M13 root-cause fix)** — internal reliability; no change to how you use the app

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.7.8/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
