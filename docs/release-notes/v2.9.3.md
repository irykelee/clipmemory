## 中文

### 主要更新 (Highlights)

- **🖱️ 大图长按预览可滚轮可关闭 (ID-VIEW-0047)** — 长按列表里的图片行打开 floating preview 大尺寸图（3000×2000 等）：之前 preview 居中屏幕中央 + 仅监测 mouseUp → 用户按住鼠标 + 滚轮时 cursor 不在 preview 上所以滚轮事件走不到 NSScrollView，**preview 无法滚动**；松手后 preview dismiss。修法 3 部分：(a) preview anchor 到 cursor（`NSEvent.mouseLocation`），clamp 到 visibleFrame 防滚条越界；(b) 同一 `targetScreen` 用于 sizing + clamp（防多屏 setup off-screen）；(c) dismiss 改 `addLocalMonitorForEvents` trackpad-scroll 合成 leftMouseUp 抑制 + Escape fallback。**强烈建议升级（之前完全无法滚动预览）**。

- **🛡️ 崩溃报告刷新后错误可见 (ID-CRASH-0006)** — `Help → View Recent Crashes` 之前只在 reports 为空时显示 errorView。**首次 load 成功后任何后续 refresh 失败 silently**（stale data + 静默丢失）。三件关缺 log + user-visible：初始 load 成功 + retry 自然但 log 完全缺席 + UI 不可见。修法：body 加 `errorBanner`（reports 非空时 compact orange 横幅显示在 table 上方）+ `logger.error` 在 catch 块（`RecentCrashesView: load failed: <reason>`）。下次 refresh 失败时 banner 出现 + 系统日志保留诊断。**强烈建议升级（用户不会以为没新崩溃而错过真 bug）**。

- **📋 Crash 报告解析不再丢字段 (ID-CRASH-0005)** — `CrashReportService.parseIPS` 之前在 multi-object body 上 silently overwrite 3 个字段：`signal = ... as? String`（第二个 object 无 signal → 第一个的 signal 被清 nil）；`binaryImages = ...`（第二个 object 无 usedImages → 第一个的 images 被清空）；`triggeredThreadFrames = ...`（同上）。pre-Ventura .ips 用 JSON array of objects，Apple 任何 spec 改动都可能触发。修法：`if let s = ... { signal = s }`（preserve）；`append(contentsOf:)`（merge）；同名 helper `append(contentsOf: parsed)`。3 个 unit test 锁住 pre-Ventura array 形态（每个 object 含不同 sub-field）。**强烈建议升级（pre-Ventura 用户实际受影响）**。

- **⚙️ GH Actions 发布恢复 fail-closed (ID-CI-0005)** — 之前 `release.yml` `Run tests` step 加 `continue-on-error: true` 让 runner-flake 时 binary 仍 ship（test fail 但 release 通过）。修法：移除 `continue-on-error`，tests 失败现在硬阻断 publish。`release.sh` 本地 preflight (`run_preflight --tests`) 是权威 gate，GH Actions 只是 smoke coverage。

- **🔍 TSan 子集验证不再漏 stale (ID-CI-0007/0009)** — `.github/workflows/tsan.yml:59` `-only-testing:ClipMemoryTests/NetworkMonitorTests` filter 是 dead reference — cdda2a6 (PR #86) 把 `NetworkMonitorTests` 重命名为 `NetworkMonitorProtocolTests` 但没更新 workflow。**6 个 network race tests 自 v2.9.2 ship 以来静默停止跑 TSan coverage**（per reviewer：cdda2a6 → ID-CI-0007 fix 之间 4 天）。同步修：(a) filter 改名 + `-ne 94` 校准（88→94 加回 6 个 NetworkMonitor tests）；(b) PR comment 改写 surface subset drift：当 assertion 失败时（filter 引用了不存在的 class）报告告诉 operator 检查类名漂移而不是说"0 races"。同步防御：3 origin unit test + monitor lifecycle test 锁住新代码。

- **🔗 ID 编号规范化（隐藏的 type 系统）** — auto-review 报告 (`docs/reviews/auto-review-*.md`, gitignored) 之前只输出 `[HIGH-N] / M-N / L-N` severity label，**没有 ID-DOMAIN-NNNN 跨文件 cross-reference 能力**。修法：going-forward rule 写入 memory，3 个历史 ID 撞车 documented（L18 ship 后 retrofit 永久禁止 → commit messages 不改），`Scripts/lint-audit-ids.sh` 在 pre-commit + push gate 跑 ID format 检查防止未来回归。

## English

### Highlights

- **🖱️ Long-press image preview can now scroll (ID-VIEW-0047)** — Pressing an image row opens a floating preview panel showing the full-size image (3000×2000 etc.). Previously: preview centered on screen + only monitored mouseUp → cursor was NOT over the preview while holding the button, so wheel events never reached `NSScrollView`, **the preview couldn't be scrolled**, and releasing the mouse dismissed it. Three-part fix: (a) preview anchors to cursor (`NSEvent.mouseLocation`), clamped to `visibleFrame` so the scrollbar can't be off-screen; (b) the same `targetScreen` is used for both sizing AND clamping (avoids multi-display off-screen pin); (c) dismissal moved from `addLocalMonitorForEvents(.leftMouseUp)` (which fired on trackpad two-finger-scroll synthesized mouseUp) to a `scrollWheel + leftMouseUp` monitor pair with a 200ms timestamp window to suppress synthesized events, plus an Escape fallback. **Strongly recommended upgrade (the preview was previously completely un-scrollable).**

- **🛡️ Crash-report refresh errors now visible (ID-CRASH-0006)** — `Help → View Recent Crashes` previously only showed `errorView` when `reports.isEmpty`. **Any subsequent refresh failure after the first successful load was silently swallowed** — stale data + invisible error. Three-piece gate was incomplete: log absent + retry natural but no log + UI invisible. Fix: body now adds an `errorBanner` (compact orange bar above the table when `reports` is non-empty) + `logger.error` in the catch block (`RecentCrashesView: load failed: <reason>`). On next refresh failure, banner appears + system log retains diagnostic. **Strongly recommended upgrade (users won't mistake a missing banner for "no new crashes" and miss real bugs).**

- **📋 Crash report parsing no longer drops fields (ID-CRASH-0005)** — `CrashReportService.parseIPS` previously silently overwrote 3 fields on multi-object bodies: `signal = ... as? String` (second object without signal → first's signal was cleared to nil); `binaryImages = ...` (second object without usedImages → first's images were cleared); `triggeredThreadFrames = ...` (same pattern). Pre-Ventura .ips uses a JSON array of objects, and any future Apple spec change could re-trigger this. Fix: `if let s = ... { signal = s }` (preserve); `append(contentsOf:)` (merge); same helper `append(contentsOf: parsed)` for all three. 3 unit tests lock the pre-Ventura array shape (each object with distinct sub-fields). **Strongly recommended upgrade (pre-Ventura users are actually affected).**

- **⚙️ GH Actions release restored to fail-closed (ID-CI-0005)** — Previous `release.yml` `Run tests` step had `continue-on-error: true` allowing runner-flake to still ship binary (test fail but release passes). Fix: removed `continue-on-error`; test failures now hard-block publish. The `release.sh` local preflight (`run_preflight --tests`) is the authoritative gate; GH Actions is just smoke coverage.

- **🔍 TSan subset verification no longer hides stale (ID-CI-0007/0009)** — `.github/workflows/tsan.yml:59` `-only-testing:ClipMemoryTests/NetworkMonitorTests` filter was a dead reference — cdda2a6 (PR #86) renamed `NetworkMonitorTests` to `NetworkMonitorProtocolTests` without updating the workflow. **6 network race tests silently stopped running TSan coverage since v2.9.2 ship** (per reviewer: 4-day gap between cdda2a6 and ID-CI-0007 fix). Synchronized fix: (a) filter rename + `-ne 94` recalibration (88→94 adding the 6 NetworkMonitor tests back); (b) PR comment rewrite surfaces subset drift: when the assertion fails (filter references a non-existent class), report tells the operator to check class-name drift rather than say "✅ 0 detected". Defense in depth: 3 origin unit tests + monitor lifecycle tests lock down new code.

- **🔗 ID numbering formalized (a hidden type system)** — auto-review reports (`docs/reviews/auto-review-*.md`, gitignored) previously only emitted `[HIGH-N] / M-N / L-N` severity labels, **lacking ID-DOMAIN-NNNN cross-file cross-reference capability**. Fix: going-forward rule written to memory, 3 historical ID collisions documented (L18 ship 后 retrofit 永久禁止 → commit messages not changed), `Scripts/lint-audit-ids.sh` runs ID format check in pre-commit + push gate to prevent future regression.
