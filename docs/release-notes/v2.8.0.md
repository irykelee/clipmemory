## English

### Highlights

- **🆕 New Gitee mirror update channel** — A mainland-China download accelerator: Settings → Update Source → Gitee (China mirror), now operating in parallel with the existing jsDelivr fallback. The Gitee sync runs on an independent workflow with self-healing dedup; the full mainland-Sparkle-push path is now live end-to-end.
- **🛡 Crypto safety hardened** — on `.cryptoKeyPrepared(success)`, this release now also clears `pendingFailedIDs` to match the existing `negativeCache` clear (ID-STORE-0010, HIGH). Previously only `negativeCache` was cleared, so an entry that just failed decryption stayed suppressed until a restart.

### Other

- **🛠 Test infrastructure hardened (NEW-1..9 + CI gate)**
  - NEW-1/2/4: production UserDefaults suite isolation + M13 inject seams (PR #29, `b3229fd`)
  - NEW-3: source-level `isRunningTests` guard on `UpdateService._sharedDefault` (`f9f7008`) — tests no longer trigger real appcast HTTP or start Sparkle updater
  - NEW-9: ZZZ canary calibration (`49f92fd`) — split `appLifecycleKeys` (10) / `toleratedPollution` (4) / `environmentInvariants` (1); cold-disk + warm-disk + bogus scenarios now deterministically green
  - CI gate: minimum test execution count enforced (`100fa61`, blind spot 6) — CI false-green from too-few-tests now caught

- **🛠 Update source fallback correctness (NEW-5/6/7)**
  - `latestVersionString` picks the last item (`e4a4204`) — no longer assumes appcast newest-first
  - `FeedProbeEngine` fallback binds by id, not array order (`9e901c5`) — misleading comment corrected
  - 5 zh-Hant 「映像」→「鏡像」 fixes (`f3e6ea9`) — GLOSSARY gate widened for the mirror word family

- **🛠 Release tooling hardened (NEW-8 + REL sandbox guard)**
  - `Scripts/release.sh` `grep -c` 0-match "0" + extra newline arithmetic fix (`9e96f63`) — was silently breaking on empty matches
  - `Scripts/rollback-release.sh` Confirm gate guard against agent-sandbox hang (`efb686d`) — `read -p < /dev/tty` was stalling in agent environments

- **🛠 Gitee sync infrastructure** (independent workflow + 6-step dedup + self-healing reruns)
  - `c60dfbb`: split Gitee mirror sync into an independent workflow
  - sync dedup 6-step pipeline: `/releases/{id}/attach_files` real endpoint + array/object dual-shape handling + upload-response attachment-id real dedup + self-healing reruns
  - diagnostic/debug commits cleaned up
  - unit tests for `FeedProbeEngine` `.gitee` case (`b68bc30`)
  - `settings.updateSource.footer` distinguishes Gitee from jsDelivr (`74ff342`)

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`
- Settings → Update Source: a new "Gitee (China mirror)" entry is now available. Defaults remain GitHub Releases + jsDelivr — no manual switch needed.
