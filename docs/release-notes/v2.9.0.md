# 剪忆 ClipMemory v2.9.0 — 备份还原向导 + 图片分享导出 / Backup Restore Wizard + Image Share & Export

**类型 / Type**: Minor release（20 commits：2 项用户可见新功能 + 1 项界面对齐 + 3 份法务文档 + 1 道翻译防回归门）

**发布日期 / Release Date**: 2026-08-14

## 中文

### 主要更新 (Highlights)

- **🗂 备份还原向导 (ID-BACKUP-0002)** — 设置 → 备份 新增「从备份还原」入口，5 步可视化向导：选择备份（每日自动备份列表，或外部 `.clipmemory` 加密包）→ 输入密码（仅外部包需要）→ 预览条目数与时间范围 → 确认 → 结果。还原**开始前自动做一次安全快照**，出错可回头；密码输错原地重试不用重来；备份不完整会提前提示，磁盘空间不足给明确报错而不是中途失败。此前从自动备份恢复数据只能手工搬 JSON 文件，现在全程有 UI。

- **🖼 图片分享 / 拖拽 / 导出到文件夹 (ID-VIEW-0030 ~ 0038)** — 图片条目现在能直接送出去，三条路径：
  - **右键「分享…」** 调起系统分享面板（隔空投送 / 信息 / 邮件 / 存储到文件均可）；多选时菜单变成「分享 N 张图片…」，一次全发
  - **直接拖拽** 列表里的图片到访达或任意 App，不用先存盘
  - **工具栏分享菜单 →「导出到文件夹…」** 选个目录批量导出。重名时弹 **替换 / 两者保留 / 取消**（「两者保留」按访达惯例加 ` (1)`、` (2)`）——**绝不静默覆盖你的文件**
  - 导出文件名沿用 ClipMemory 内部存储名，访达里看到的和应用里一致
  - 配套把主窗口最小宽度从 850 提到 950，窄窗口下工具栏的分享和清空按钮不再被折叠进 » 溢出菜单

- **📌 侧边栏「置顶」显示条数徽章 (ID-VIEW-0029)** — 与其他筛选 tab 对齐，一眼看到置顶了几条。

- **⚖️ 补齐 MIT LICENSE + 隐私政策 + 使用条款 (ID-LEGAL-0001)** — 仓库新增 `LICENSE`（MIT）、`PRIVACY.md`、`TERMS.md`。此前项目公开但无许可证，法律上等同「保留所有权利」，别人不能安全地 fork 或二次分发；现在授权关系明确。隐私政策白纸黑字写明：所有剪贴板数据加密后只留在本机，不上传任何服务器。

- **🌐 翻译一致性防回归门 (ID-LINT-0001)** — 新增 `Scripts/lint-translations.sh`，以 `LocalizationService.swift` 为唯一真相源，校验 221 个 key × 7 语种全覆盖，缺一个翻译 CI 直接红（已接进 pre-commit 和 CI）。顺手清掉 4 个 v2.7.x 遗留的死 key。用户侧的收益是：以后新功能不会再出现某个语种漏翻、界面上蹦出英文 key 名。

### 升级提示 (Upgrade Note)

## English

### Highlights

- **🗂 Backup restore wizard (ID-BACKUP-0002)** — Settings → Backup now has a "Restore from Backup" entry point, a 5-step visual wizard: pick a backup (from the daily automatic backup list, or an external encrypted `.clipmemory` package) → enter the password (external packages only) → preview the item count and date range → confirm → result. A **safety snapshot is taken automatically before the restore starts**, so a bad restore is recoverable; a wrong password can be retried in place instead of restarting the flow; incomplete backups are flagged up front, and insufficient disk space produces an explicit error rather than a mid-way failure. Previously, recovering from an automatic backup meant moving JSON files by hand — now the whole path has a UI.

- **🖼 Image share / drag / export to folder (ID-VIEW-0030 – 0038)** — Image entries can now leave the app through three routes:
  - **Right-click → "Share…"** opens the system share sheet (AirDrop / Messages / Mail / Save to Files all work); with a multi-selection the menu becomes "Share N Images…" and sends them all at once
  - **Drag directly** from the list into Finder or any app — no need to save first
  - **Toolbar share menu → "Export to Folder…"** picks a directory and exports in bulk. On a filename conflict you get **Replace / Keep Both / Cancel** ("Keep Both" appends ` (1)`, ` (2)` per Finder convention) — **your files are never silently overwritten**
  - Exported filenames reuse ClipMemory's internal storage name, so what you see in Finder matches what you see in the app
  - The main window minimum width was raised from 850 to 950 so the toolbar's share and clear buttons stop collapsing into the » overflow menu on narrow windows

- **📌 Pinned count badge in the sidebar (ID-VIEW-0029)** — Brings the Pinned tab in line with the other filter tabs, so the pinned count is visible at a glance.

- **⚖️ MIT LICENSE + Privacy Policy + Terms of Service added (ID-LEGAL-0001)** — The repository now ships `LICENSE` (MIT), `PRIVACY.md`, and `TERMS.md`. The project was public but unlicensed, which legally means "all rights reserved" — nobody could safely fork or redistribute it. The licensing terms are now explicit. The privacy policy states plainly that all clipboard data is encrypted and stays on your machine, and is never uploaded to any server.

- **🌐 Translation parity regression gate (ID-LINT-0001)** — New `Scripts/lint-translations.sh` treats `LocalizationService.swift` as the single source of truth and verifies all 221 keys across 7 languages; a single missing translation turns CI red (wired into both pre-commit and CI). Four dead keys left over from v2.7.x were removed along the way. The user-facing benefit: new features can no longer ship with an untranslated locale that leaks raw key names into the UI.

### Upgrade Note

- Minor release: no breaking changes, no data migration; v2.8.4 users upgrade automatically with history and settings untouched
- The restore wizard is a **new** entry point — it does not change existing daily automatic backups or encrypted export behavior
- Image share / export applies to image entries only; the context menu for text and link entries is unchanged
- Main window minimum width 850 → 950: if you had manually shrunk the window below that, it will widen to 950 on first launch after upgrading
- 825/825 tests green

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.9.0/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
