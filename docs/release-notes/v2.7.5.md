# 剪忆 ClipMemory v2.7.5 — 紧急修复 / Critical Hotfix

**发布日期 / Release Date**: 2026-07-31
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- **修复图片预览右侧空白条** — 竖屏上打开接近屏幕高度的长截图时，预览面板右侧出现大片空白区域，现已按图片实际宽度自适应显示
- **修复自动更新检测器死代码** — v2.7.4 的 Sparkle 自动更新检测器未启动，导致该版本**无法收到本版本的自动更新推送**。已在 v2.7.5 修复，后续版本自动更新恢复正常
- **修复回收站操作崩溃** — 删除或恢复回收站内项目时可能触发崩溃（或静默操作到错误的项目），现已修复

### 修复 (Fixes)

- **修复防抖保存定时器静默失效** — 标签编辑、回收站操作等非即时落盘路径的防抖保存，在首次触发后会停止工作；崩溃或强制退出将丢失上一次启动后的全部标签/回收站变更
- **修复含回收站条目的备份无法导入** — 任何包含非空回收站的备份文件在导入时都会失败，现已兼容
- **修复回收站列表文字/链接行显示为空** — v2.7.4 引入的回归：回收站的非图片项目行不显示文字，现已修复
- **修复标签建议、徽章旁白 6 语种翻译** — v2.7.4 的 VoiceOver 标签补丁误将中文写入了全部语种；现已提供英/日/韩/西/葡/繁中正确翻译

### 升级提示 (Upgrade Note)

- **⚠️ v2.7.4 用户**：v2.7.4 的自动更新检测器未启动，**您不会收到 v2.7.5 的自动推送**。请手动升级：`brew upgrade --cask clipmemory` 或从 GitHub Releases 下载 `ClipMemory.tar.gz` 手动替换 `/Applications/ClipMemory.app`
- v2.4.0 起带自动更新模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **Fix image preview blank strip** — full-height screenshots on portrait screens showed a blank panel strip on the right; the panel now hugs the image's actual width
- **Fix dead auto-update checker** — v2.7.4's Sparkle update checker never started, so that version **will never receive automatic update notifications for this release**. Fixed in v2.7.5 — auto-update resumes for future versions
- **Fix trash operation crash** — moving items to or restoring from trash could crash (or silently target the wrong item), now fixed

### Fixes

- **Fix debounced save timers going silent** — tag edits, trash ops, and other non-immediate saves would stop working after the first flush; force-quit or crash lost all tag/trash changes since launch
- **Fix backup import with non-empty trash** — any backup containing trash items always failed to import, now compatible
- **Fix empty text/link rows in trash list** — a v2.7.4 regression caused non-image trash rows to render blank, now fixed
- **Fix 6-locale VoiceOver translations** — v2.7.4's accessibility patch pasted Chinese into all locales; en/ja/ko/es/pt/zh-Hant now have correct translations for tag suggestions and badge counts

### Upgrade Note

- **⚠️ v2.7.4 users**: the v2.7.4 update checker never started, so **v2.7.5 will NOT be delivered to you automatically**. Please upgrade manually: `brew upgrade --cask clipmemory`, or download `ClipMemory.tar.gz` from GitHub Releases and replace `/Applications/ClipMemory.app`
- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.7.5/ClipMemory.tar.gz
```

> **首次打开若提示「Apple 无法验证…」/ If macOS blocks the first launch with "Apple cannot verify…"**：这是 macOS 对未公证应用的常规拦截，不是病毒。右键点 App →「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 →「仍要打开」。仅需操作一次。/ This is the standard prompt for non-notarized apps, not malware. Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
