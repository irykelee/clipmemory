# 剪忆 ClipMemory v2.7.7 — 搜索体验与可靠性修复 / Search Experience & Reliability Fixes

**发布日期 / Release Date**: 2026-08-01
**类型 / Type**: Patch release

## 中文

### 主要更新 (Highlights)

- **搜索不再卡顿** — 搜索含富文本的历史时，此前会在主线程逐条解密导致明显卡顿；现在冷缓存条目先跳过、后台预热完成后自动出现在结果中
- **QuickBar 搜索更完整** — 搜索时未解密的条目此前会被静默漏掉且不会补全；现在预热完成后结果自动刷新补全
- **重复条目自动合并** — 启动密钥就绪后，历史中的重复条目（含此前启动窗口期漏网积累的）现在会自动合并清理
- **图片浏览更快** — 图片读取不再被后台的旧格式迁移任务阻塞

### 修复 (Fixes)

- **修复回收站条目整会话空白** — 登录自启动且密钥链尚未解锁时，回收站的文本/链接条目此前一直空白且不自愈
- **主窗口搜索框支持回车复制** — 搜索框内按回车现在直接复制选中的（或第一条）结果，与 QuickBar 行为一致
- **修复单个格式错误的标签连坐全部标签丢失** — 标签数据字段类型异常时单条降级，不再拖垮整个标签列表
- **修复备份包导入安全校验** — 导入的备份包在解压前即校验成员路径合法性，阻断路径穿越风险
- **修复备份保留份数调整的并发竞争** — 调低保留份数后的立即清理不再与进行中的备份互相干扰
- **修复设置页字号选择器** — 选项标签误显示为「设置为」、且不显示当前选中值
- **OCR 回填防停滞** — 图片文字批量回填遇到异常实现永不回调时不再永久卡死
- **加密与内部质量加固** — 解密诊断缓存语义与规格对齐；剪贴板监控、挂起检测、日期格式化的并发安全强化；测试与生产数据全面隔离（消除测试运行污染真实数据的一类隐患）

### 升级提示 (Upgrade Note)

- v2.4.0 起带自动更新模块（Sparkle）的版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`

## English

### Highlights

- **Search no longer stutters** — searching history containing rich text previously decrypted item-by-item on the main thread, causing visible stutter; cold-cache items are now skipped and appear automatically once background prewarming completes
- **More complete QuickBar search** — undecrypted items used to be silently dropped from results and never came back; results now refresh automatically after prewarming
- **Automatic duplicate merging** — once the encryption key is ready after launch, duplicate entries in history (including ones accumulated during previous launch windows) are now merged and cleaned up automatically
- **Faster image browsing** — image reads are no longer blocked by background legacy-format migration

### Fixes

- **Fix trash rows staying blank for the whole session** — with login launch and a locked Keychain, trash text/link rows stayed blank and never recovered
- **Return key now copies from the main-window search field** — pressing Return copies the selected (or first) result, matching QuickBar behavior
- **Fix one malformed tag wiping the whole tag list** — a tag entry with wrong-typed fields now degrades individually instead of taking down all tags
- **Fix backup package import validation** — imported backup packages now validate member paths before extraction, blocking path traversal
- **Fix backup pruning race** — pruning after lowering the retention count no longer races with an in-flight backup
- **Fix the font-size picker in Settings** — the option label wrongly showed "Set to" and the current value was not displayed
- **OCR backfill no longer stalls** — batch image-text backfill no longer hangs forever if a recognition implementation never calls back
- **Encryption & internal hardening** — decryption diagnostic cache semantics aligned with spec; concurrency safety strengthened for the clipboard monitor, hang detector, and date formatting; full test/production data isolation (eliminating a class of test-run pollution of real data)

### Upgrade Note

- Versions with the auto-update module (Sparkle, v2.4.0+): wait for in-app auto-update, or run `brew upgrade --cask clipmemory`

## 安装 / Install

```bash
# Homebrew Cask
brew tap irykelee/clipmemory
brew trust irykelee/clipmemory
brew install --cask clipmemory

# Manual download
# https://github.com/irykelee/clipmemory/releases/download/v2.7.7/ClipMemory.tar.gz
```

Right-click the app → **Open** → **Open** again; or System Settings → Privacy & Security → **Open Anyway**. Only needed once.
