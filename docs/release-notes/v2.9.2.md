## 中文

### 主要更新 (Highlights)

- **⚡ 启动主线程不再卡顿 (P2-14)** — `ClipboardStore.init` 此前同步解码全部历史（10K 条目 = 100-300ms main thread stall），并引入 5 个旁路 bug（窗口期 addItem merge race → 可能覆盖全量历史 / OCR 启动回填在 production 100% 跳过 / Cmd+Q 后 applicationShouldTerminate drain 写截断快照 / applicationWillTerminate 不等 firstLoad / bg-thread 通过 `RunLoop.main` 在非 main thread mutate `@Published`）。修法：detached 后台 Task + `SyncBarrier`（`firstLoadTask` / `firstLoadCompleted` / `waitForFirstLoad` / `waitForFirstLoadSync`）+ merge-instead-of-discard（窗口期 addItem 不丢用户数据，per `never-silently-change-user-choices.md`）+ conditional scheduleSave（窗口触发 + repair 触发）+ `applicationShouldTerminate` drain 加 `DispatchQueue.main.sync` 跳到 main + `dispatchPrecondition(.onQueue(.main))` 防退化。**强烈建议升级（启动体感 + 数据完整性双收）**。

- **⚡ 剪贴板捕获路径优化 (P2-13)** — `addItem` 此前每次都同步写盘（100 次连续复制 = 100 次 main-thread JSON encode + UserDefaults write → 50-200ms per capture × 100 = 5-20s 主线程占用）。修法：`scheduleSave` 500ms 防抖 coalesce；保留 `applicationWillTerminate` 立即 flush 路径保优雅退出持久性；持久性强度被新加的 3 测钉住（P2-13 契约：100-item burst coalesce + 防偶发 flush 测试 + capture-time 不写盘契约）。

- **🖼️ 图片缩略图与异步全尺寸 (P2-16)** — `copyToClipboard` 此前可能写 ≤512px 缩略图到 NSPasteboard（不是用户复制的全分辨率）。Round-2 redesign：thumbnail preview cache（UI 列表缩略图）与 fullSize cache（copy-to-clipboard 时取）分离；`copyToClipboard` 走 `cachedFullSizeImageObject` 异步预热避免阻塞 UI；3 个新测钉住"复制是全分辨率不是缩略图"契约（TIFF 字节数 vs 缩略图上限）。

- **🔧 关键静默失败修复 (P2-2/3/4/6/7/15)** — 6 项审计发现的 silent failure：(P2-2) `saveBlob` 检测内存写失败并 loud log + 抛错；(P2-3) Keychain 迁移失败分类 transient vs permanent（transient 重试、permanent 立刻抛错）；(P2-4) `restoreFromTrash` 现在 trim 到 cap + dedup（防 restore 触发 overflow 又走 trash）；(P2-6) `detectSensitive` 保守标记 >50KB 内容（防漏标）；(P2-7) capture gate 拒绝纯空白 + IC-1 follow-up 拒绝 whitespace-only RTF；(P2-15) NSCache cost 设置让 `totalCostLimit` 实际生效（之前 cost=0 → limit 失效 → OCR 缓存可无限增长）。

- **🛠️ ClipboardStore 拆分扩展 (P2-8, 部分)** — `ClipboardStore` god object 按 ARCH pattern 新增 4 个 topic extension：`+History` / `+OCR` / `+Tag` / `+Utilities`（per PR #57/#59/#60 的 persistence/prewarm/encryption 同模式）。**主文件 2305 行仍超 swiftlint `file_length.error:1250` 上限**，`// swiftlint:disable file_length` 仍需保留 — 进一步拆分待后续 patch（完整拆分需 ≥5 个 PR，per ARCH 系列规模）。

- **🛡️ 独立审核 hook 上线 (OpenCode auto-review)** — pre-push hook 跑 OpenCode 跨系统独立 review（`~/.opencode/bin/opencode run --model <non-claude>`），VERDICT=FAIL（含 P0/P1）阻断 push。3-state PR comment + scope 严格按被推分支范围算（per `feedback/user-delegates-tech-decisions.md` 长期约束）。本版本 P2-14 修法迭代 4 轮（round-1 revert → round-2 conditional save → round-3 OCR/terminate gate → round-4 bg-thread main.sync），每轮都被该 hook 抓到真 regression（如 P1-1 OCR 永远跳过 + P1-2 terminate truncate + P1 bg race）。

## English

### Highlights

- **⚡ Startup no longer blocks main thread (P2-14)** — `ClipboardStore.init` previously decoded the entire history synchronously (10K items = 100-300ms main-thread stall) and introduced 5 latent data-loss / race windows (window-addItem merge race → could overwrite full history / OCR startup backfill silently skipped in production / Cmd+Q truncate-overwrite by applicationShouldTerminate drain / applicationWillTerminate not awaiting firstLoad / bg-thread pumping RunLoop.main to mutate `@Published` off-main). Fix: detached background Task + `SyncBarrier` primitives (`firstLoadTask` / `firstLoadCompleted` / `waitForFirstLoad` / `waitForFirstLoadSync`) + merge-instead-of-discard (preserves user data per `never-silently-change-user-choices.md`) + conditional scheduleSave (window-trigger + repair-trigger) + `applicationShouldTerminate` drain now wraps flush in `DispatchQueue.main.sync` + `dispatchPrecondition(.onQueue(.main))` defends against future bg callers. **Strongly recommended upgrade (startup feel + data integrity both improve).**

- **⚡ Capture path coalescing (P2-13)** — `addItem` previously wrote through synchronously per capture (100 copies = 100 main-thread JSON encode + UserDefaults writes → 50-200ms × 100 = 5-20s main-thread occupancy for a 100-item burst). Fix: `scheduleSave` 500ms debounce coalesce; preserves graceful-quit durability via `applicationWillTerminate` flush; 3 new tests pin the contract (P2-13 100-item burst coalesces + no-spurious-flush guard + capture-time no-write-through invariant).

- **🖼️ Image thumbnail + async full-size (P2-16)** — `copyToClipboard` previously could write a ≤512px thumbnail to NSPasteboard instead of the user's full-resolution copy. Round-2 redesign: separate thumbnail preview cache (UI list) from fullSize cache (pasteboard copy); `copyToClipboard` consults `cachedFullSizeImageObject` with async prewarm avoiding UI blocking; 3 new tests pin the "copy is full-resolution not thumbnail" contract (TIFF byte count vs thumbnail upper bound).

- **🔧 Key silent-failure fixes (P2-2/3/4/6/7/15)** — Six audit-found silent failures: (P2-2) `saveBlob` detects in-memory write failures with loud log + throw; (P2-3) Keychain migration failures classified transient vs permanent (transient retry, permanent throw immediately); (P2-4) `restoreFromTrash` now trims to cap + dedupes (prevents restore from triggering overflow back into trash); (P2-6) `detectSensitive` conservatively flags >50KB content (prevents under-flagging); (P2-7) capture gate rejects pure-whitespace content + IC-1 follow-up rejects whitespace-only RTF; (P2-15) NSCache cost set so `totalCostLimit` actually enforces (previously cost=0 → limit ineffective → OCR cache could grow unbounded).

- **🛠️ ClipboardStore extension split (P2-8, partial)** — `ClipboardStore` god object gained 4 topic extensions per the ARCH pattern (`+History` / `+OCR` / `+Tag` / `+Utilities`), continuing the same extension-split pattern established by PR #57/#59/#60 (persistence/prewarm/encryption). **Main file still 2305 lines (exceeds swiftlint `file_length.error:1250` cap)** — `// swiftlint:disable file_length` remains required. Further splits deferred to follow-up patches (full split requires ≥5 PRs, per ARCH series scope).

- **🛡️ Independent review hook online (OpenCode auto-review)** — pre-push hook runs OpenCode cross-system independent review (`~/.opencode/bin/opencode run --model <non-claude>`); VERDICT=FAIL (P0/P1 present) blocks push. 3-state PR comment + scope strictly computed per pushed branch (per `feedback/user-delegates-tech-decisions.md` long-term constraint). P2-14 this cycle required 4 rounds of iteration (round-1 revert → round-2 conditional save → round-3 OCR/terminate gate → round-4 bg-thread main.sync), each round caught a real regression the hook (P1-1 OCR silently skipped + P1-2 terminate truncate + P1 bg-thread race).
