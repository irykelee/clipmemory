## English

### Highlights

- **🖱️ Portrait display long-press preview position fix (ID-VIEW-0048)** — On a portrait display, long-pressing a large image opened the preview at the bottom-left of the screen (0, 0), far from the cursor, and mouse-wheel couldn't scroll the preview. **Root cause**: `ImagePreviewPanel.show()` gets the cursor with `NSEvent.mouseLocation` (y-down screen coords), then uses `NSMouseInRect(_, _, false)` to detect which screen the cursor is on. Per Apple's docs: `flipped: false` = rect is treated as y-up (Cocoa view default), `flipped: true` = rect is treated as y-down (Quartz screen default). `NSScreen.visibleFrame` is y-down but `flipped: false` made `mouse.y` (y-down) compare against `visibleFrame` (treated as y-up) → y-axis mismatch → every screen missed, `.first(where:)` returned nil → fallback `?? screen` (nil) → used default `1440×900` + origin `(0, 0)`. On a 1080×1920 portrait display, origin (0, 0) is the **bottom-left corner** — far from the cursor. **Fix**: `flipped: false` → `flipped: true` (commit `a1cd997`, already in v2.9.3 source). **Portrait users strongly recommended upgrade** (previously couldn't even see the image content, just had to close the panel).

- **🛠 v2.9.3 GH Actions Test substep compatible release path (ID-RELEASE-0003 / ID-CI-0011 / ID-CI-0012)** — The v2.9.4 tag (`149906d`) temporarily added `|| true` to `release.yml`'s `Run tests` step as a workaround (**the actual mechanism shipped at that point**); `main` reverted it in `da3cc6a`, and `ID-CI-0011` linter forbids re-introduction. Test substep still runs, but failures are swallowed; `xcodebuild test | tee log` on GH macOS default shell has no `pipefail`, so tee's exit 0 means `|| true` never fires (fail-open is tee's accident, not `|| true`'s function); `Build Release` covers app target only, **not test target** — a wholly broken test suite can ship behind a green workflow. **Known limitations**:
  - Known flake signature is P2-14 SyncBarrier 5s timeout (ClipboardStore.swift:515); v2.9.3 failure not matched against it → unconfirmed whether same flake
  - `/tmp/xcb-release-test.log` not readable by GH admin (runner ephemeral, no `upload-artifact`)
  - Local preflight (`Scripts/release.sh vX.Y.Z --yes` calls `run_preflight --tests` internally by default — see `release.sh:992`; `--skip-tests` skips tests but keeps the other gates) is the authoritative gate; the v2.9.4 tag's CI test step was advisory smoke, but `main` (`da3cc6a`) restored fail-closed
  - Compensating control shipped: `Scripts/lint-release-yml.sh` + ci.yml `lint-ids` job `release.yml fail-open policy check (ID-CI-0011)` step (landed in `a0da7f5`, real bugs fixed in `bb90453` ID-CI-0012, docs round-2 fixed in `6847507` ID-CI-0013; current state has the 5-fixture self-test wired)
