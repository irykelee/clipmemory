# 剪忆 ClipMemory v2.7.3 — Audit-Driven Fixes & 7-Language VoiceOver / 审计驱动修复与 7 语言 VoiceOver 无障碍

**发布日期 / Release Date**: 2026-07-30
**类型 / Type**: Patch release

> 本版本收录自 v2.7.2 以来的 4 个 commit，约 40 项审计驱动修复（19 fix + 13 WONTFIX + 10 silent）。重点是性能 / 生命周期 / 无障碍三块的连续治理。/ This release bundles 4 commits since v2.7.2 with ~40 audit-driven fixes (19 fix + 13 WONTFIX + 10 silent-error surfaces). Focus: continuous improvements on performance, lifecycle, and accessibility.

## 中文

### 主要更新 (Highlights)

- **🚀 性能提升（多项后台优化）** — JSONEncoder 复用、缓存预热并发上限、清理任务单遍扫描、冷启动 AES-GCM 解密预填；数千条历史下粘贴与搜索明显更顺
- **🌐 7 语言 VoiceOver 无障碍** — 主菜单 / 搜索框 / 欢迎页 / 标签 chip / 应用排除列表 / 日期过滤按钮 / 剪贴板项类型标签全部本地化；非英语用户首次可用 VoiceOver 流畅使用
- **🧹 生命周期加固** — 关闭欢迎/设置窗口不再内存泄漏；TrashStore / FeedProbeEngine 在 deinit 时正确清理后台任务；ImageStorage 在 App 退出前 flush 未完成写入
- **🔇 沉默错误改为可见** — 10 处 `try?` 吞错点现在记录到日志并通知 UI（图片迁移写失败、孤儿文件残留、备份暂存目录清理失败等），便于排查

### 修复 (Fixes)

- **AES-GCM 解密失败不再永久污染条目** — Keychain 瞬态锁定时触发的解密失败，现在 key 恢复后会自动重试（旧 bug 会永久标记条目不可解密）
- **重复复制图片不再产生重复文件** — 图片去重改用 contentHash 集合 O(1) 查询（之前 O(n) 全表扫描 + legacy 条目逐条解密比对）
- **Sparkle 更新完成后窗口不会莫名消失** — 更新结束时只在没有可见窗口时才把 App 图标模式切到 accessory（避免 stranded window 无 Dock / cmd-Tab 入口）
- **ImageStorage 退出时数据丢失** — App 退出前 flush 未落盘的图片写入（旧 bug：kill -9 / 断电可丢图）
- **多个 deinit 内存泄漏** — TrashStore / FeedProbeEngine / Trash / 定时器 / NotificationCenter observer 在测试场景或进程退出路径下不再悬挂
- **QuickBar 键盘选择不会越界** — onReturn 加上 `idx >= 0` 防御 guard
- **App Picker 图标加载防 stale** — 切换 bundleId 后老图标不会被写回（cancel-aware guard）

### 升级提示 (Upgrade Note)

- v2.7.2 或更早版本：等 App 内自动更新，或 `brew upgrade --cask clipmemory`
- 升级后**首次启动**会自动触发启动时图片完整性扫描（与 v2.7.2 行为一致；不阻塞 App 启动），列表中标记 ⚠️ 的条目可在 Trash 中查看详情
- 7 语言用户：升级后立即生效；VoiceOver 无需额外配置

## English

### Highlights

- **🚀 Performance (multiple background optimizations)** — JSONEncoder reuse, prewarm concurrency cap, single-pass cleanup, cold-start AES-GCM prefill. Copy & search feel noticeably smoother with thousands of history items
- **🌐 7-Language VoiceOver accessibility** — Main menu / search field / welcome page / tag chip / app exclusion list / date filter buttons / clipboard item type labels all localized. Non-English users can now use VoiceOver fluently for the first time
- **🧹 Lifecycle hardening** — Closed welcome/settings windows no longer leak. TrashStore / FeedProbeEngine properly cancel background tasks on deinit. ImageStorage flushes in-flight writes before app quit
- **🔇 Silent errors surface visibly** — 10 `try?` error-swallow sites now log to os_log AND notify the UI (image migration write failures, orphan file residue, backup staging cleanup failures, etc.) for easier triage

### Fixes

- **AES-GCM decryption failure no longer permanently poisons items** — Keychain transient lock failures now auto-retry after key recovery (previously, items were permanently labeled undecryptable)
- **Image dedup no longer creates duplicate files** — Switched to O(1) contentHash set lookup (was O(n) full scan + per-legacy-item decrypt-compare)
- **Sparkle update no longer vanishes open windows** — Update-end icon-mode switch to .accessory now only fires when no visible window exists (prevents stranded windows without Dock/cmd-Tab presence)
- **ImageStorage quit-time data loss** — App quit now flushes in-flight image writes (was vulnerable to kill -9 / power loss)
- **Multiple deinit leaks** — TrashStore / FeedProbeEngine / timer / NotificationCenter observers no longer linger in tests or process-exit paths
- **QuickBar keyboard selection bounds-checked** — Added `idx >= 0` defensive guard in onReturn
- **App Picker icon load is stale-safe** — Cancel-aware guard prevents writing stale icons when bundleId changes mid-load

### Upgrade Note

- v2.7.2 or earlier: wait for in-app auto-update, or `brew upgrade --cask clipmemory`
- **First launch after upgrade** runs the startup image integrity scan (same as v2.7.2; non-blocking); items marked ⚠️ can be inspected in Trash
- 7-language users: takes effect immediately on upgrade; VoiceOver needs no extra setup
